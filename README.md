# 识字工坊 hanzi-studio

两个能力，一套核心代码，Web Demo 和微信小程序共用：

1. **字族图生成器**：输入一个汉字 → 按「3 本义 + 3 生活 + 2 动作 + 1 反差」策划 9 个词（拼音 / 英文 / 图标描述）→ 直接排版出图（3:4 / 1:1 / 16:9，4 套画风）+ 生图提示词（中/英、有字版/无字版）+ 7 项质检与返工策略 + 批量打包。
2. **拍照识字 + 复习**：拍一张家里的照片（比如冰箱）→ 物品上直接浮出汉字和拼音 → 点一下听读音、看笔顺、跟着写 → 自动进入间隔复习，复习题用孩子自己拍的照片。

## 目录

```
core/            共享逻辑（UMD，浏览器 / 小程序 / Node 都能用）
  lexicon.js     内置词库：16 个字 × 9 词，18 个家居物品
  planner.js     词组策划提示词、生图提示词、自动质检、7 项人工质检、返工策略
  render.js      Canvas 2D 排版渲染器（椭圆分布 + 碰撞松弛 + 自动缩放）
  ai.js          大模型请求构造/解析：Claude、通义千问 VL、豆包、DeepSeek、任意 OpenAI 兼容接口
  srs.js         间隔复习（Leitner 盒子，1/2/4/7/15/30/60 天）
  demo.js        示例冰箱插画 + 已知坐标
web/             Web Demo（纯静态，无需构建）
miniprogram/     微信小程序（原生）
cloudfunctions/aiProxy/  云函数：代理大模型，Key 只放服务端
scripts/sync.js  把 core 和依赖同步到 web/ 与 miniprogram/
```

## 运行 Web Demo

```bash
npm i pinyin-pro@3.26.0 hanzi-writer@3.7.2 hanzi-writer-data@2.0.1 jszip@3.10.1
node scripts/sync.js
cd web && python3 -m http.server 8000   # 打开 http://localhost:8000
```

不填 Key 也能用：16 个内置字、示例冰箱、手动标注、复习都离线可用。在「设置」里填 Key 后可以策划任意汉字、识别真实照片。

## 运行小程序

1. 微信开发者工具 → 导入项目，选仓库根目录（`project.config.json` 已指向 `miniprogram/`）。
2. 「设置 → 第三方设置 → 插件管理」添加 **微信同声传译**（朗读用）。
3. 大模型二选一：
   - **云函数（上线用这个）**：开通云开发，上传 `cloudfunctions/aiProxy`，在云函数环境变量里配 `AI_PROVIDER`（`openai` / `anthropic`）、`AI_BASE`、`AI_MODEL`、`AI_KEY`。国内推荐 `qwen-vl-max`（通义千问 VL）。
   - 直连（只用于调试）：在小程序里进入「模型设置 → 直连」填 Key，并把接口域名加入 request 合法域名。
4. 非内置字的笔顺数据从 `cdn.jsdelivr.net` 加载，需要加入合法域名，或者改成自己的 CDN。

## 拍照识字是怎么实现的

```
拍照 → 压缩到 1280px JPEG → 视觉大模型（一次调用）
     → JSON: [{zh, pinyin, en, emoji, box[0~1000], sentence, sentence_en}]
     → 前端按 box 把标签贴到物品上（逐个弹出）
     → 点标签：朗读 + 田字格笔顺 + 描红 + 例句
     → 按 box 裁出物品缩略图，存入复习卡片
```

- **一次调用拿到全部信息**：识别、命名、拼音、英文、位置、例句都在一个请求里完成，通常 3~6 秒出结果。通义千问 VL 原生支持 0~1000 坐标定位，框更准。
- **拼音二次校验**：模型给的拼音再用 pinyin-pro 对一遍。字族图的质检也是同样的做法，不一致时标「请人工确认」，不自动覆盖，因为词典在多音字上也会错（例如 心脏 zàng、种花 zhòng）。
- **识别不了也能用**：没有 Key、或者模型漏了某样东西时，家长点照片上的位置再输入词语，就能手动标注，拼音自动补全。
- **复习用自己的照片**：复习题是从原图裁出来的物品，不是通用插画。孩子看到的是「我家冰箱里那盒酸奶」，比卡片记得牢。

### 让它「更实时」的下一步

| 阶段 | 做法 | 效果 |
| --- | --- | --- |
| 现在 | 拍一张 → 云端视觉模型 | 3~6 秒，识别范围最广 |
| 下一步 | 端侧检测先出框（小程序 VisionKit / Web 用 TF.js COCO-SSD），常见 80 类直接查本地中英词典，同时把图发给云端补全长尾物品 | 第一批标签不到 1 秒就出来，云端结果到了再补 |
| 再下一步 | 相机实时取景（`<camera>` + `onCameraFrame`），对准什么就显示什么 | 「对着冰箱扫一圈」的体验 |

### 后续可以加的

- **小动画 / 故事**：用当次识别出的词让大模型编 3~5 句小故事（「小兔子打开冰箱，拿出一根胡萝卜……」），生词高亮可点读。`ai.js` 里加一个 `storyMessages(words)` 就行。
- **英文同样适用**：数据里已经同时有 `zh` 和 `en`，把学习页的主语言切成英文就是「拍照学英语」。
- **复习提醒**：小程序订阅消息，在有词到期时推送「今天有 5 个词要复习」。
- **家长报告**：每周汇总学了多少词、哪些总答错。

## 质检清单（出图后）

1. 主字字形正确 → 局部重绘中心
2. 拼音声调正确 → 无字版 + 排版补字
3. 9 个词齐全且都含主字 → 重新策划
4. 英文释义准确 → 无字版 + 排版补字
5. 图标与词义对应 → 局部重绘单张卡
6. 版式完整 → 整图重抽
7. 风格统一干净 → 整图重抽

中文字被生图模型写错时，最稳的办法是「无字版」：模型只画图标和版式，文字由本工具的 Canvas 排版盖上去，保证 100% 准确。
